# BUNNY WALK WIDGET 개인정보처리방침 · 지원

iOS 앱 "BUNNY WALK WIDGET"(DBNB STUDIO)의 App Store 등록용 공개 페이지입니다.

- 개인정보처리방침: `index.html`
- 지원 및 문의: `support.html`

원본은 앱 저장소의 `docs/privacy-policy.md`이며, 이 저장소는 GitHub Pages 배포용입니다.

## app-ads.txt

`app-ads.txt`는 AdMob 광고 판매자 인증 파일입니다. 이 저장소(GitHub Pages 하위 경로)에서는 인식되지 않으므로, 개발자 웹사이트 도메인 루트(`https://dbnbstudio.com/app-ads.txt`)에 그대로 올려야 합니다.
